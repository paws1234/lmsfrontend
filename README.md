# CTU LMS — Frontend (Vue 3)

The Vue single-page app for the CTU LMS: Vue 3, Vue Router and an axios client
that speaks to the Laravel API in its own repository
(<https://github.com/paws1234/lmsbackend>).

## Run with Docker

```bash
docker compose up -d --build
```

Open <http://localhost:8080>. See [DOCKER.md](DOCKER.md) for configuration,
the full command reference and troubleshooting.

## Project setup

```
npm install
```

### Compiles and hot-reloads for development

```
npm run serve
```
